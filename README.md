粟湾/如仁 自动化题库同步中心
一款基于 Python 和 Streamlit 开发的自动化题库采集与管理工具，专为“粟湾/如仁”平台设计。支持多账号批量登录、验证码智能识别、题目自动去重同步及可视化管理。
✨ 功能亮点
🚀 批量自动同步：支持一次性输入多个账号密码，系统将全自动依次登录并同步指定课程的题库。
🧠 智能 OCR 识别：内置 ddddocr 引擎，全自动处理登录验证码，无需人工干预。
📊 详细同步报告：实时显示每个账号的同步进度，并在完成时汇总显示每个账号贡献的新题数量。
🔍 题库在线管理：
筛选与搜索：按课程筛选或关键词搜索题目。
精准删除：支持单题删除或一键清空指定课程题库。
导出功能：支持将题库导出为标准 JSON 格式，且文件名自动匹配课程名称。
⚙️ 课程配置管理：动态添加、编辑或删除需要监控的课程 URL。1

🛠️ 技术栈
Frontend/UI: Streamlit
Crawler: Requests + BeautifulSoup4
OCR: ddddocr
Data: JSON 本地持久化储存

📖 使用指南
左侧边栏：输入账号和密码（格式：账号 密码，每行一个）。
同步选项卡：选择目标课程，点击“开始同步更新”。
浏览选项卡：查看已抓取的题目，进行搜索、单题删除、整库清空或导出 JSON。
管理选项卡：添加或删除需要同步的课程链接。

📂 项目结构
app.py: 系统主程序
requirements.txt: 项目依赖列表
database.json: 本地题目数据库（自动生成）
courses_config.json: 课程配置信息（自动生成）
start.bat: Windows 环境一键启动脚本
